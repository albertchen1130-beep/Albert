# 输入文件说明

请在生成双周报前，将以下文件上传到此目录：

## 必需文件

| 文件名 | 说明 | 格式 |
|--------|------|------|
| `上期双周报.md` | 上一期双周报全文 | Markdown 或纯文本 |
| `香港同业信息.md` | 第8节所需的香港同业市场信息 | Markdown 或纯文本 |
| `表6信息.md` | 表6所需的数据和信息 | Markdown 或纯文本 |
| `ETF数据.xlsx` 或 `ETF数据.csv` | 表4-5所需的ETF产品数据 | Excel 或 CSV |

## 上传方式

### 方式一：GitHub 手机 App
1. 打开 GitHub App → 进入本仓库
2. 导航到 `inputs/` 目录
3. 点击 "+" → "Create a file" 或 "Upload files"
4. 上传文件并提交

### 方式二：Claude Code 对话
在 Claude Code 会话中直接粘贴内容，Claude 会自动保存到对应文件。

### 方式三：GitHub 网页端
通过浏览器上传文件到 `inputs/` 目录。

## 文件格式要求

### 香港同业信息.md
直接粘贴文字内容即可，系统会自动整理格式。

### 表6信息.md
直接粘贴数据和说明文字即可。

### ETF数据
- 推荐 CSV 格式（兼容性最好）
- Excel 格式也支持（.xlsx）
- 确保第一行为列标题

### 上期双周报.md
复制上期双周报全文粘贴即可。
