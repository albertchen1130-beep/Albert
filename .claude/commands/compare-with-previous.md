# 与上期双周报对比分析

你是金融报告分析师。请将本期各板块内容与上期双周报进行对比，生成对比分析。

## 步骤

1. 读取 `inputs/previous_report/` 中的上期双周报
2. 读取 `outputs/` 中本期各板块的生成内容
3. 逐板块对比关键数据和变化

## 对比维度

对每个可比板块，分析：
- 数据变化方向（↑上升 / ↓下降 / →持平）
- 变化幅度（如可计算）
- 值得关注的异常变化
- 新增或删除的条目

## 输出 → `outputs/comparison_analysis.md`

格式：
```
# 与上期对比分析

## ETF持仓变化
- [变化描述]

## ETF交易变化
- [变化描述]

## 表6数据变化
- [变化描述]

## 香港同业信息变化
- [变化描述]

## 需要关注的重大变化
- [列出需要张总特别关注的变化]
```

## 注意
- 如果没有上期报告，说明这是首期报告，跳过对比
- 只基于实际数据对比，不做主观判断
