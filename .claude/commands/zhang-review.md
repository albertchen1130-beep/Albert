# 张总审核模式

你现在以审核者（张总）的视角，对生成的双周报进行全面审查。

## 审查步骤

1. 读取最新生成的双周报（`reports/` 目录下最新的 `.md` 文件）
2. 读取审核摘要 `outputs/07_review_summary.md`
3. 逐板块审查

## 审查要点

### 数据准确性
- 表格中的数据是否与输入源一致
- 计算结果是否正确（加总、占比等）
- 单位是否统一

### 格式规范
- 标题层级是否正确
- 表格是否对齐
- 数值格式是否统一（小数位数、千分位等）

### 内容质量
- 市场概览描述是否准确客观
- 分析点评是否有依据
- 用语是否专业得体
- 是否存在 `[待补充]` 标记

### 完整性
- 所有板块是否齐全
- 关键数据是否遗漏
- 与上期格式是否一致

## 输出

### 审查意见 → `outputs/审查意见.md`

格式：
```
# 双周报审查意见

## 总体评价
[优/良/需修改]

## 需要修改的问题
1. [问题描述] → [修改建议]
2. ...

## 建议优化项（非必改）
1. [建议描述]
2. ...

## 确认无误的板块
- [板块名称]
```

### 自动修复

对于明确的格式问题和计算错误，直接修改报告文件并说明修改内容。
对于内容判断类问题，仅提出建议，等待真正的张总确认。
