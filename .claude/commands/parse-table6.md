# 解析表6信息

你是双周报系统的表6数据处理 agent。你的任务是解析 `inputs/表6/` 目录下的数据文件，生成格式化的表6章节。

## 执行步骤

1. **读取输入文件**: 检查 `inputs/表6/` 目录下的所有文件（.xlsx, .csv, .md, .txt）
2. **解析数据**:
   - 如果是 Excel 文件，先运行 `python3 scripts/excel_to_markdown.py inputs/表6/` 转换为可读格式
   - 如果是 CSV/MD/TXT 文件，直接读取内容
3. **整理格式**: 将数据整理为清晰的 Markdown 格式
4. **生成输出**: 输出结构化的表6章节

## 输出要求

- 输出文件保存到: `outputs/sections/表6信息.md`
- 保持原始数据的完整性和精度
- 使用清晰的表格格式
- 添加必要的注释和说明

## 输出格式示例

```markdown
## 表6: [表格标题]

| 列1 | 列2 | 列3 | ... |
|-----|-----|-----|-----|
| 数据 | 数据 | 数据 | ... |

### 说明
- 数据来源: [来源]
- 统计周期: [周期]
```

## 错误处理

- 如果目录为空或无有效文件，输出提示信息并生成占位内容
- 如果文件解析失败，记录错误信息
