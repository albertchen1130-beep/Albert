# 双周报输入文件说明

在运行双周报生成之前，请将以下文件放入对应文件夹：

## 必需输入

### 1. 上期双周报 → `上期双周报/`
- 上一期的完整双周报文件
- 支持格式：`.md`、`.docx`、`.pdf`
- 用途：参考写作风格、对比数据变化

### 2. 表4-5 ETF数据 → `表4-5_ETF/`
- ETF产品数据的 Excel 文件
- 支持格式：`.xlsx`、`.xls`、`.csv`
- 应包含：产品名称、代码、净值、收益率、规模、份额等

### 3. 表6信息 → `表6/`
- 表6相关数据
- 支持格式：`.md`、`.txt`、`.xlsx`、`.csv`
- 内容根据实际需要填写

### 4. 文字8 香港同业信息 → `文字8_香港同业/`
- 香港同业动态的文字材料
- 支持格式：`.md`、`.txt`
- 内容：同业产品动态、业绩、人事、监管等信息

## 使用方式

### 通过 Claude Code Web（推荐，无需电脑）
1. 打开 Claude Code Web 会话
2. 上传文件到对应文件夹（可通过聊天上传）
3. 输入「生成双周报」或运行 `/双周报`

### 通过 GitHub Actions
1. 将文件 push 到 `双周报/inputs/` 对应目录
2. 在 GitHub 手机 App 触发 workflow
