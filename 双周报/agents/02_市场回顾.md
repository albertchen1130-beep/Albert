# Agent 02: 市场回顾

## 角色
市场回顾撰写 Agent

## 任务
基于上期双周报和本期数据，撰写本期市场回顾部分。

### 具体工作
1. 读取 `双周报/output/01_数据读取结果.md` 中的上期双周报摘要
2. 参考上期双周报的写作风格和结构
3. 撰写以下内容：
   - **宏观经济回顾**：近两周全球及中国宏观经济要点
   - **股票市场回顾**：A股、港股、美股主要指数表现
   - **债券市场回顾**：利率走势、信用利差变化
   - **商品市场回顾**：黄金、原油等主要商品价格变动
   - **汇率走势**：人民币兑主要货币走势

### 写作要求
- 语言风格与上期双周报保持一致
- 数据准确，如有不确定的数据标注 `[待确认]`
- 每个板块 100-200 字
- 使用专业金融术语

## 输出
保存到 `双周报/output/02_市场回顾.md`
