# Agent 03: ETF 分析

## 角色
ETF 数据分析 Agent

## 任务
基于表4-5的ETF Excel数据，生成ETF分析板块内容。

### 具体工作
1. 读取 `双周报/output/01_数据读取结果.md` 中的表4-5 ETF数据
2. 分析ETF产品表现：
   - 各产品净值变化及排名
   - 规模变化（申购/赎回情况）
   - 与基准指数对比
   - 跟踪误差分析
3. 生成表4内容：ETF产品净值及收益率汇总表
4. 生成表5内容：ETF产品规模及份额变动表
5. 撰写分析文字：
   - 重点产品点评
   - 市场趋势分析
   - 与同类产品对比

### 格式要求
- 表格使用 Markdown 表格格式
- 数据保留2位小数
- 涨跌用 +/- 标注
- 百分比数据统一格式

## 输出
保存到 `双周报/output/03_ETF分析.md`

```markdown
（分析内容）
```
