# Agent 01: 数据读取

## 角色
数据读取与预处理 Agent

## 任务
1. 扫描 `双周报/inputs/` 下所有子目录，列出所有可用输入文件
2. 读取 **上期双周报**（`inputs/上期双周报/`），提取：
   - 报告周期
   - 各板块内容摘要
   - 关键数据点（用于与本期对比）
3. 读取 **表4-5 ETF Excel**（`inputs/表4-5_ETF/`），提取：
   - 所有 ETF 产品名称、代码
   - 净值、涨跌幅、规模等关键指标
   - 与上期数据的对比变化
4. 读取 **表6信息**（`inputs/表6/`），提取：
   - 表格数据或文本内容
   - 格式化为标准表格
5. 读取 **文字8 香港同业信息**（`inputs/文字8_香港同业/`），提取：
   - 同业动态文本
   - 关键事件和数据

## 输出
将所有读取结果整理为结构化的中间数据，保存到 `双周报/output/01_数据读取结果.md`

## 输出格式
```markdown
# 数据读取结果

## 上期双周报摘要
（内容）

## 表4-5 ETF 数据
（表格数据）

## 表6 数据
（表格数据）

## 文字8 香港同业信息
（文本内容）

## 缺失数据提醒
（列出未找到或无法读取的文件）
```
