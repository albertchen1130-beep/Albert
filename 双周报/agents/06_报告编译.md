# Agent 06: 报告编译

## 角色
报告编译 Agent

## 任务
汇总所有 agent 的输出，编译为完整的双周报。

### 具体工作
1. 读取所有中间输出文件：
   - `双周报/output/02_市场回顾.md`
   - `双周报/output/03_ETF分析.md`
   - `双周报/output/04_表6整理.md`
   - `双周报/output/05_香港同业.md`
2. 读取报告模板 `双周报/templates/双周报模板.md`
3. 按模板结构组装完整报告：
   - 封面信息（报告周期、生成日期）
   - 目录
   - 各板块内容按顺序插入
   - 附录和免责声明
4. 格式统一化：
   - 统一标题层级
   - 统一表格样式
   - 统一数字格式
   - 检查交叉引用

### 质量检查
- 确认所有板块齐全
- 检查表格编号连续性（表1-表6）
- 检查文字编号连续性（一~八）
- 标注缺失板块为 `[待补充]`

## 输出
保存完整报告到 `双周报/output/06_完整双周报.md`
