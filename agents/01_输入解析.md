# Agent 1：输入解析

## 职责

解析用户上传到 `inputs/` 目录的所有输入文件，提取结构化数据供后续 Agent 使用。

## 执行步骤

1. **扫描 `inputs/` 目录**，确认以下文件存在：
   - `上期双周报.md` — 上一期双周报全文
   - `香港同业信息.md` — 第8节香港同业信息原始文字
   - `表6信息.md` — 表6相关数据
   - `ETF数据.xlsx` 或 `ETF数据.csv` — 表4-5的ETF数据

2. **读取并解析各文件**：
   - 对于 Markdown/文本文件：直接读取内容
   - 对于 Excel/CSV 文件：使用 Python 脚本解析，提取表格数据
   - 记录每个文件的内容摘要

3. **数据验证**：
   - 检查 ETF 数据是否包含必要列（基金名称、规模、净值、涨跌幅等）
   - 检查文本内容是否为空
   - 标记任何数据质量问题

4. **输出结构化数据**到 `outputs/parsed_data.json`：
   ```json
   {
     "上期双周报": { "content": "...", "sections": [...] },
     "香港同业信息": { "content": "..." },
     "表6信息": { "content": "..." },
     "ETF数据": { "columns": [...], "rows": [...] },
     "解析状态": "成功/部分成功/失败",
     "问题": [...]
   }
   ```

## 缺失文件处理

如果任何输入文件缺失：
- 列出缺失文件清单
- 提示用户："请通过 GitHub App 上传以下文件到 inputs/ 目录，或在对话中直接粘贴内容"
- 对于已有的文件，继续处理

## ETF Excel 解析脚本

如果需要解析 Excel，使用以下 Python 代码：

```python
import csv
import json

def parse_csv(filepath):
    with open(filepath, 'r', encoding='utf-8-sig') as f:
        reader = csv.DictReader(f)
        return list(reader)

def parse_excel(filepath):
    # 尝试用 openpyxl（如果可用）
    try:
        import openpyxl
        wb = openpyxl.load_workbook(filepath, data_only=True)
        sheets = {}
        for name in wb.sheetnames:
            ws = wb[name]
            headers = [cell.value for cell in ws[1]]
            rows = []
            for row in ws.iter_rows(min_row=2, values_only=True):
                rows.append(dict(zip(headers, row)))
            sheets[name] = rows
        return sheets
    except ImportError:
        print("openpyxl 不可用，请将 Excel 转为 CSV 格式")
        return None
```
