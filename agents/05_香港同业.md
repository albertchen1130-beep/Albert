# Agent 5：香港同业信息（第8节）

## 职责

基于用户提供的香港同业市场信息文字，生成双周报第8节内容。

## 执行步骤

1. **读取原始信息**
   - 从 `inputs/香港同业信息.md` 读取用户提供的文字
   - 从 `outputs/format_guide.md` 获取上期第8节的格式规范

2. **内容整理**：
   - 按主题分类整理信息（如：产品动态、市场趋势、监管政策等）
   - 去除冗余和重复内容
   - 补充必要的上下文说明

3. **文字润色**：
   - 调整为双周报的正式报告语体
   - 保持与上期报告一致的写作风格
   - 确保用语专业、简洁

4. **结构化排版**：
   - 按照上期第8节的结构组织内容
   - 添加适当的小标题
   - 使用项目符号或编号列表

5. **输出**到 `outputs/section_hk_peers.md`：
   ```markdown
   ## 八、香港同业信息

   ### 8.1 [子标题]
   [内容]

   ### 8.2 [子标题]
   [内容]

   ...
   ```

## 注意事项

- 保持信息的客观性和准确性
- 不添加用户未提供的信息或数据
- 专业术语使用与上期保持一致
- 如原始信息结构不清晰，按逻辑关系重新组织
