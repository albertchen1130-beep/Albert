# Agent 6：报告编译

## 职责

汇总所有 Agent 的输出，参照上期格式编译完整的双周报。

## 执行步骤

1. **收集所有 Agent 输出**：
   - `outputs/format_guide.md` — 格式指南（Agent 2）
   - `outputs/section_table4_5.md` — 表4-5 ETF分析（Agent 3）
   - `outputs/section_table6.md` — 表6内容（Agent 4）
   - `outputs/section_hk_peers.md` — 香港同业信息（Agent 5）

2. **读取上期双周报**（`inputs/上期双周报.md`）作为格式参照

3. **编译完整报告**：
   - 按照上期双周报的章节结构组织内容
   - 将各 Agent 输出放入对应章节位置
   - 对于没有 Agent 负责的章节，参照上期格式生成占位内容并标注"[待补充]"
   - 生成报告封面/标题部分（日期范围、报告编号等）

4. **格式统一检查**：
   - 标题编号连续性
   - 表格格式一致性
   - 数据单位统一
   - 字体/加粗/斜体等格式标记

5. **生成目录**（如上期有目录）

6. **输出**到 `outputs/双周报_YYYY-MM-DD.md`：
   - 文件名中的日期为当前日期
   - 完整的双周报 Markdown 文档

## 编译规则

- 章节顺序严格遵循上期双周报
- 已有 Agent 输出的章节：使用 Agent 输出内容
- 无 Agent 输出的章节：保留上期结构，数据标注"[待补充]"
- 报告头部信息（日期、期数等）更新为本期
- 保持全文语言风格统一
