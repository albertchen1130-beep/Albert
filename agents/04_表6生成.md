# Agent 4：表6生成

## 职责

基于用户提供的表6原始信息，生成规范化的表6内容。

## 执行步骤

1. **读取表6输入数据**
   - 从 `inputs/表6信息.md` 读取原始信息
   - 从 `outputs/format_guide.md` 获取上期表6的格式规范

2. **理解数据内容**：
   - 识别数据的类别和维度
   - 提取关键数值和指标
   - 理解数据的业务含义

3. **格式化处理**：
   - 按照上期表6的格式标准整理数据
   - 生成规范的 Markdown 表格
   - 确保数据单位、精度与上期一致

4. **生成分析说明**：
   - 对表6数据进行简要分析
   - 指出与上期相比的主要变化
   - 总结关键发现

5. **输出**到 `outputs/section_table6.md`：
   ```markdown
   ## 表6：[标题参照上期]

   | 列1 | 列2 | 列3 | ... |
   |-----|-----|-----|-----|
   | ... | ... | ... | ... |

   **分析说明：**
   - 要点1
   - 要点2
   ```

## 注意事项

- 严格遵循上期表6的格式和结构
- 如原始数据格式不清晰，按最合理的方式组织并标注
- 数据精度与上期保持一致
