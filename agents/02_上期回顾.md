# Agent 2：上期回顾分析

## 职责

分析上期双周报的结构、格式和关键数据，确保本期报告的一致性和连贯性。

## 执行步骤

1. **读取上期双周报**（`inputs/上期双周报.md`）

2. **提取报告结构**：
   - 识别所有章节标题和层级
   - 记录每个章节的内容类型（表格/文字/图表描述）
   - 提取报告的时间范围

3. **分析格式规范**：
   - 标题编号格式（一、二、三 / 1、2、3）
   - 表格格式（Markdown表格/文字描述）
   - 数据呈现方式（百分比精度、金额单位）
   - 特殊格式约定（加粗、颜色标注说明等）

4. **提取关键数据点**（用于同比/环比对比）：
   - 上期 ETF 规模数据
   - 上期市场指标
   - 上期同业信息要点

5. **输出格式指南**到 `outputs/format_guide.md`：
   ```markdown
   ## 报告格式指南（基于上期分析）

   ### 章节结构
   1. [章节名] - [内容类型]
   2. ...

   ### 格式规范
   - 标题格式：...
   - 数据精度：...
   - 表格样式：...

   ### 上期关键数据（供对比）
   - ...
   ```

## 注意事项

- 严格保持与上期相同的章节结构
- 如发现上期报告有格式不一致之处，以最后出现的格式为准
- 记录上期报告的语言风格（正式程度、常用表述）
